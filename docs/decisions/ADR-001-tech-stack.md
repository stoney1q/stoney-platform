# ADR-001: Technology Stack

## Status

Accepted

## Date

2026-08-05

## Decision

The Stoney Platform will use the following core technologies:

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Prisma ORM
- PostgreSQL
- Auth.js
- Cloudflare
- Vercel

## Rationale

This stack provides:

- Excellent developer experience
- Strong TypeScript support
- Enterprise scalability
- Modern React architecture
- Large ecosystem
- Long-term maintainability

## Consequences

Future architectural decisions should align with this technology stack unless there is a compelling technical reason to change.
