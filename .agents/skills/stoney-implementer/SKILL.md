# Stoney Platform — Implementer Skill

**Purpose**: Implement an APPROVED implementation plan. This is the primary coding skill.

## Required Behavior

You may:

- Create files.
- Modify source code.
- Add tests.
- Modify UI.
- Modify server actions.
- Modify validation.
- Modify configuration when explicitly included in the approved plan.

You must NOT:

- Expand scope silently.
- Change architecture without approval.
- Modify unrelated business logic.
- Create migrations unless explicitly approved.
- Run destructive database commands without explicit approval.
- Commit or push.

## Pre-modification Check

Before modifying a file, verify that the file is inside the approved implementation boundary (the `implementation_plan.md`).

## Handling Architectural Problems

If implementation reveals an architectural problem:
**STOP.**

Report:

# IMPLEMENTATION BLOCKER

# DISCOVERY

# IMPACT

# PROPOSED CHANGE

# APPROVAL REQUIRED

Do not silently redesign the system.

"Use the stoney-implementer skill to execute the approved Loop 10 plan."
